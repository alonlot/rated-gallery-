# Test portraits

Public-domain portraits from the NASA Image and Video Library (images-assets.nasa.gov), resized to 1200 px.
NASA material is generally not subject to copyright in the United States. The tests use the people in them only
as anonymous identities ("me", "dana", "other1", "other2"). File to NASA ID mapping: scripts/fetch_test_faces.py.
These files are only for automated tests. They are not part of anyone's photo library.
